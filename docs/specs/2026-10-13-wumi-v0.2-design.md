# Wumi v0.2「图表 + 多币种」设计

## 0. 交付范围与顺序

| 批次 | 内容 | 任务数 |
|------|------|--------|
| P0 前置清理 | 负余额解析 `-¥`、canSave 转账分支补测、类型切换清空补测、导出快照函数收敛（`BackupManager.snapshot()` 单点） | 1 |
| P1 多币种 | currencies 表 + 种子、账户币种放开、汇率管理页、自动拉取（可关）、外币记账快照可改、转账限同币种 | ~6 |
| P2 图表 | 图表 tab 五图：分类环形、分类排行、每日柱状、近 6 月对比柱状、近 6 月趋势折线 | ~4 |
| P3 验收 | 月报数字与手算一致（自动化集成测试）+ 属性测试 + 迁移测试 | 1 |

**验收标准**（spec §8）：月报数字与手算一致。

**刻意不做（YAGNI）**：汇率历史曲线、自定义图表配置、图表导出图片、跨币种转账、汇率手动排序、Wi-Fi-only 拉取。

**Room 迁移**：schema 1→2 新增 `currencies` 表，正式 Migration（保 v0.1 用户数据），禁止 fallbackToDestructiveMigration。

## 1. 数据模型

### 1.1 新实体 CurrencyEntity（表 `currencies`）

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String PK | ISO 4217（USD/EUR/JPY…） |
| name | String | 显示名（美元） |
| symbol | String | 符号（$） |
| decimals | Int | 小数位（JPY=0、BHD=3，与 Money.decimalsOf 同口径） |
| rateToBase | String | **1 外币 = ? CNY**，BigDecimal 字符串（金额铁律） |
| rateUpdatedAt | Long | 汇率更新时间 epochMillis |
| id / createdAt / updatedAt / deletedAt / deviceId | | 同步基因五字段（v0.3 汇率同步免迁移） |

**预置种子 20 币种**：CNY(rate=1 基准) + USD/EUR/JPY/HKD/TWD/KRW/SGD/THB/MYR/VND/AUD/GBP/CHF/CAD/NZD/INR/RUB/BRL/EGP/SEK。首启幂等插入（`COUNT=0` 守卫，与默认分类同法），初装给合理缺省汇率（如 USD≈7.1），可手改可拉取。

### 1.2 换算规则（金额铁律落地）

- `baseAmountMinor = round(amountMinor × BigDecimal(rateToBase), HALF_UP)`，统一收敛在新纯 JVM 对象 `FxConverter`。
- 属性测试：任意金额 × 汇率 ÷ 汇率 往返误差 ≤ 1 分（spec §10，200 组随机样本）。
- 本位币账户 rate 恒 1，不参与 currencies 表语义。

### 1.3 既有实体

- `AccountEntity.currency` 字段 v0.1 已存在，仅放开 UI。
- 交易表**零改动**（currency / exchangeRate / baseAmountMinor 已埋）。
- Migration 1→2：`CREATE TABLE currencies`（含同步基因列）+ room-testing 迁移测试断言 v0.1 数据保全。

## 2. 汇率管理

### 2.1 汇率管理页（我的 → 「汇率管理」新增入口，标签页占位不动）

- 列表：`符号 代码`｜`1 USD = 7.12 CNY`｜更新时间（相对时间）｜点击行弹对话框手输新汇率（实时校验 >0 且 BigDecimal 可解析）。
- 顶部「立即更新」按钮：拉取全部非 CNY 币种；成功 Snackbar「已更新 N 个币种」，失败 Snackbar「更新失败，请检查网络」（静默原则不弹窗）。
- 顶部 Switch：自动拉取开关（settings 表 key `autoFxRate`，默认开）；关闭即取消 WorkManager 排队任务。

### 2.2 自动拉取

- WorkManager 周期 7 天，约束 `NetworkType.CONNECTED`；成功后下次周期再拉，无重试链（失败等下周期，页面可手动补）。
- 数据源：`open.er-api.com/v6/latest/CNY`（免费无 key、币种全、以 CNY 为基准，正好匹配 rateToBase 语义）。
- HTTP 用 `HttpURLConnection`（~40 行）；OkHttp 留给 v0.3 同步层，不为拉汇率引依赖。
- 解析规则：只取预置 20 币种交集；单币种非法（0/负/解析失败）跳过不更新该币种；**成功的币种逐个更新 `rateToBase` 与各自的 `rateUpdatedAt`**（列表按币种显示各自更新时间，无全局时间戳）。

## 3. 多币种记账与账户

### 3.1 外币记账（RecordSheet 改造）

- 选外币账户 → 金额输入为**外币金额** → 键盘上方折算条 `≈ ¥5.08 · 汇率 7.12（点按修改）`。
- 点折算条弹对话框改**当笔汇率**（预填当日汇率），折算即时重算；`exchangeRate` 存当笔快照字符串，历史不随波动重算（spec §5.3）。
- 本位币账户：无折算条，零交互成本。
- 汇率缺失（种子未及/被清）：弹对话框强制手输，不阻塞记账。

### 3.2 账户

- 新建/编辑放开币种下拉（默认 CNY；选外币显示当前汇率提示；**建户时若该币种汇率缺失，引导先到汇率管理页补齐，不允许以无汇率状态建户**）。
- 列表余额：外币账户主行显外币原值（`$1,000.00`），副行折算 `≈ ¥7,120.00`。

### 3.3 转账限制

- 源/目标**同币种才可转**；跨币种目标在列表置灰 + 文案「暂不支持跨币种转账」。

## 4. 图表页（五图，替换现有占位页）

### 4.1 布局（单 LazyColumn 自上而下）

```
[‹ 2026年10月 ›]                     ← 月切换（复用明细页模式）
[本月支出 ¥X  收入 ¥Y]               ← 汇总卡（baseAmountMinor 口径）
① 分类占比环形图 [支出|收入] chips     ← Canvas drawArc 自绘 + 中心总额
② 分类排行列表                       ← emoji｜金额+占比%｜进度条，与①双向高亮联动
③ 每日收支柱状图                      ← Vico ColumnChart，当月每日双柱（支出红/收入金）
④ 近 6 月对比柱状                     ← Vico ColumnChart，月度双柱
⑤ 近 6 月趋势折线                     ← Vico LineChart，收支两线
```

### 4.2 技术构成

- **Vico 2.x**（spec §4 选型）：柱状/折线三图；米金/红双系列主题。
- **环形图 Compose Canvas 自绘**：`drawArc` 扇区 + 中心文字 + 点击命中检测（角度反解）；12 色序列由种子色 HSL 旋转派生；0 值分类不渲染扇区。绘制逻辑拆纯函数（扇区角度计算）供 Robolectric 测试。
- **数据口径**：全部 `baseAmountMinor` 本位币聚合 + `deletedAt IS NULL`；DAO 新增 `sumByCategory(from,to,type)` / `sumByDay(from,to)` / `sumByMonth(近6月)` 三个聚合查询，Repository 暴露 Flow。
- **包结构**：`ui/stats/`（StatsViewModel + StatsScreen + DonutChart + 排行列表）。
- **空态与加载态**：`null` 区分（吸取 T9 Minor），空月显空态文案不闪现。

## 5. 错误处理

| 场景 | 处理 |
|------|------|
| 拉取失败/超时（10s） | 手动：Snackbar 提示；自动：静默等下周期 |
| 拉取部分成功 | 只更新合法币种；全部成功才刷 rateUpdatedAt |
| 汇率非法（0/负/解析失败） | 拉取时跳过该币种；手输实时校验拒绝 |
| 外币账户汇率缺失 | 建户校验汇率存在且 >0；记账时弹框强制手输 |
| 图表空数据 | null 区分空态/加载态 |
| 迁移失败 | 迁移测试兜底（数据保全断言） |

## 6. 测试策略

| 层 | 内容 |
|----|------|
| 纯 JVM | FxConverter 换算（HALF_UP、0.01 与 9 位数边界）；汇率 JSON 解析三路径（正常/部分失败/非法值） |
| 属性测试 | 金额 × 汇率 × 逆汇率往返 ≤1 分，200 组随机样本（spec §10） |

| DAO | 3 个聚合查询边界（空月/全删月/跨币种混合） |

| 前置清理回归 | 负余额解析、canSave 转账分支、类型切换清空（P0 三补测） |
