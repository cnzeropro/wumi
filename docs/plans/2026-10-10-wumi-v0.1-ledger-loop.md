# Wumi v0.1「记账闭环」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 v0.1 记账闭环——Android 工程骨架、账户/二级分类/三类交易 CRUD、明细页、本地每日滚动备份（7 份）、CSV/JSON 导出；验收：能完整记一天账、杀进程不丢数据。

**Architecture:** 单 Activity + Navigation Compose；MVVM（StateFlow）；Room 为唯一真相源，每个业务实体自带同步基因（id/createdAt/updatedAt/deletedAt/deviceId），Repository 写业务表与 outbox 在同一事务——v0.1 建好可合并地基，同步引擎 v0.3 才接入。

**Tech Stack:** Kotlin 2.x、Jetpack Compose + Material 3、Room、Hilt、WorkManager、kotlinx-serialization、JUnit4 + Robolectric + Compose UI Test。

**Spec:** `docs/specs/2026-09-14-wumi-design.md`（§5 数据模型、§7 UI、§8 分期表 v0.1 行、§10 测试策略）

## Global Constraints

- applicationId `org.zero.wumi`；versionName `0.0.1`、versionCode `1`
- minSdk 35 / targetSdk 36 / compileSdk 36
- 单 module `:app`，分包：`data/`、`ui/`、`di/`、`work/`、`util/`
- 金额一律 `Long` 最小单位（分）；汇率存字符串；禁止 Float/Double 存金额
- 业务实体必带同步基因：`id: String`(UUIDv7)、`createdAt: Long`、`updatedAt: Long`、`deletedAt: Long?`、`deviceId: String`
- 删除一律软删除（写 `deletedAt`）；账户下有交易只能归档（spec §9.2）
- UI 中文；应用名 `Wumi · 吾米记账`；开屏 slogan 主"吾米蓄财，智理未来"副"Wealth & Me, Hand in Hand"
- 依赖版本执行时取最新稳定版（Task 1 的 toml 为基线，升级保持 API 兼容）
- 每任务结束 `git commit`；测试命令在仓库根目录运行；Windows 下用 `gradlew.bat`（PowerShell 写作 `.\gradlew.bat`）
- v0.1 不做：同步引擎、图表、预算、周期记账、导入、应用锁、小组件（spec §8/§11）

```kotlin
package org.zero.wumi.ui.theme

import android.os.Build
import androidx.compose.foundation.isSystemInDarkTheme
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.darkColorScheme
import androidx.compose.material3.dynamicDarkColorScheme
import androidx.compose.material3.dynamicLightColorScheme
import androidx.compose.material3.lightColorScheme
import androidx.compose.runtime.Composable
import androidx.compose.ui.platform.LocalContext

private val LightColors = lightColorScheme(primary = WumiSeed)
private val DarkColors = darkColorScheme(primary = WumiSeed)

@Composable
fun WumiTheme(
    dynamicColor: Boolean = false,   // spec：默认关，品牌色为准
    content: @Composable () -> Unit,
) {
    val dark = isSystemInDarkTheme()
    val scheme = when {
        dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S -> {
            val ctx = LocalContext.current
            if (dark) dynamicDarkColorScheme(ctx) else dynamicLightColorScheme(ctx)
        }
        dark -> DarkColors
        else -> LightColors
    }
    MaterialTheme(colorScheme = scheme, typography = WumiTypography, content = content)
}
```

```kotlin
import androidx.navigation.compose.rememberNavController
import org.zero.wumi.ui.navigation.Routes
import org.zero.wumi.ui.navigation.WumiNavHost

private data class Tab(val route: String, val label: String, val icon: androidx.compose.ui.graphics.vector.ImageVector)

@Composable
fun WumiApp() {
    val nav = rememberNavController()
    val backStack by nav.currentBackStackEntryAsState()
    val current = backStack?.destination?.route
    val tabs = listOf(
        Tab(Routes.OVERVIEW, "明细", Icons.Filled.Savings),
        Tab(Routes.STATS, "图表", Icons.AutoMirrored.Filled.PieChart),
        Tab(Routes.BUDGET, "预算", Icons.Filled.AccountBalanceWallet),
        Tab(Routes.MINE, "我的", Icons.Filled.Person),
    )
    Scaffold(
        floatingActionButton = { FloatingActionButton(onClick = { /* Task 8 接入记一笔 */ }) { Icon(Icons.Filled.Add, "记一笔") } },
        bottomBar = {
            NavigationBar {
                tabs.forEach { t ->
                    NavigationBarItem(
                        selected = current == t.route,
                        onClick = { nav.navigate(t.route) { popUpTo(Routes.OVERVIEW) { saveState = true }; launchSingleTop = true; restoreState = true } },
                        icon = { Icon(t.icon, t.label) },
                        label = { Text(t.label) },
                    )
                }
            }
        },
    ) { padding ->
        androidx.compose.foundation.layout.Box(androidx.compose.ui.Modifier.padding(padding)) { WumiNavHost() }
    }
}
```

`Uuid7.kt`（RFC 9562：48bit 毫秒时间戳 + 版本 7 + 随机段；同毫秒内靠 SecureRandom 唯一）:
```kotlin
package org.zero.wumi.util

import java.security.SecureRandom

private val random = SecureRandom()

/** RFC 9562 UUIDv7，时间有序（spec §5.1：客户端生成、离线可造）。 */
fun uuid7(nowMillis: Long = System.currentTimeMillis()): String {
    val bytes = ByteArray(16)
    val ts = nowMillis
    bytes[0] = (ts ushr 40).toByte(); bytes[1] = (ts ushr 32).toByte()
    bytes[2] = (ts ushr 24).toByte(); bytes[3] = (ts ushr 16).toByte()
    bytes[4] = (ts ushr 8).toByte();  bytes[5] = ts.toByte()
    random.nextBytes(bytes)
    bytes[6] = ((bytes[6].toInt() and 0x0F) or 0x70).toByte()  // version 7
    bytes[8] = ((bytes[8].toInt() and 0x3F) or 0x80).toByte()  // RFC variant
    val hex = bytes.joinToString("") { "%02x".format(it) }
    return "${hex.substring(0,8)}-${hex.substring(8,12)}-${hex.substring(12,16)}-${hex.substring(16,20)}-${hex.substring(20)}"
}
```

`Money.kt`:
```kotlin
package org.zero.wumi.util

import java.math.BigDecimal
import java.math.RoundingMode
import java.text.DecimalFormat
import java.util.Locale

/** 金额工具：一律 Long 最小单位（分），显示层格式化（spec §5.3 金额铁律）。 */
object Money {
    private val symbols = mapOf("CNY" to "¥", "JPY" to "¥", "USD" to "$", "EUR" to "€")

    fun format(minor: Long, currency: String): String {
        val decimals = decimalsOf(currency)
        val sym = symbols[currency] ?: "$currency "
        val sign = if (minor < 0) "-" else ""
        val abs = kotlin.math.abs(minor)
        return if (decimals == 0) "$sign$sym$abs"
        else {
            val whole = abs / pow10(decimals)
            val frac = abs % pow10(decimals)
            val pattern = "#,##" + "0".repeat(decimals - 1).let { "" } // 占位，下一行真正构造
            val fmtWhole = java.text.DecimalFormat("#,###", java.text.DecimalFormatSymbols(Locale.US))
            "$sign$sym${fmtWhole.format(whole)}." + frac.toString().padStart(decimals, '0')
        }
    }

    fun parseToMinor(text: String, decimals: Int): Long? {
        val cleaned = text.replace(",", "").trim().removePrefix("¥").removePrefix("$").trim()
        if (cleaned.isEmpty()) return null
        return try {
            BigDecimal(cleaned).setScale(decimals, RoundingMode.HALF_UP)
                .movePointRight(decimals).longValueExact()
        } catch (e: ArithmeticException) { null } catch (e: NumberFormatException) { null }
    }

    fun decimalsOf(currency: String): Int = when (currency) {
        "JPY", "KRW", "VND" -> 0
        "BHD", "IQD", "JOD", "KWD", "LYD", "OMR", "TND" -> 3
        else -> 2
    }

    private fun pow10(n: Int): Long = BigDecimal.TEN.pow(n).longValueExact()
}
```

```kotlin
            val v = UUID.randomUUID().toString()
            dao.put(SettingEntity("deviceId", v))
            return v
        } finally { db.close() }
    }
```

```kotlin
import android.content.Context
import dagger.Module
import dagger.Provides
import dagger.hilt.InstallIn
import dagger.hilt.android.qualifiers.ApplicationContext
import dagger.hilt.components.SingletonComponent
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.runBlocking
import org.zero.wumi.data.local.WumiDatabase
import org.zero.wumi.data.local.entity.SettingEntity
import java.util.UUID
import javax.inject.Qualifier
import javax.inject.Singleton

@Qualifier annotation class DeviceId

@Module
@InstallIn(SingletonComponent::class)
object DeviceModule {
    /** 业务注入用：首次访问生成并持久化。 */
    @Provides @Singleton @DeviceId
    fun deviceId(@ApplicationContext ctx: Context): String = runBlocking {
        val db = (ctx.applicationContext as? android.app.Application)?.let { app ->
            runCatching { dagger.hilt.android.EntryPointAccessors.fromApplication(app, DbEntryPoint::class.java).db() }.getOrNull()
        } ?: Room.databaseBuilder(ctx, WumiDatabase::class.java, "wumi.db").build()
        try {
            val dao = db.settingDao()
            dao.get("deviceId")?.let { return@runBlocking it }
            UUID.randomUUID().toString().also { dao.put(SettingEntity("deviceId", it)) }
        } finally { if (db !is dagger.hilt.android.internal.managers.ApplicationComponentManager) db.close() }
    }
}
```

```kotlin
@Singleton
class AccountRepository @Inject constructor(
    private val db: WumiDatabase,
    @DeviceId private val deviceId: String,
) {
    fun observeAll() = db.accountDao().observeAll()

    suspend fun save(id: String?, name: String, emoji: String, currency: String, initialBalanceMinor: Long, type: Int, creditLimitMinor: Long?, billingDay: Int?, includeInNet: Boolean) {
        val now = System.currentTimeMillis()
        db.withTransaction {
            val old = id?.let { db.accountDao().getById(it) }
            val e = (old ?: AccountEntity(uuid7(now), name, emoji, currency, initialBalanceMinor, type, creditLimitMinor, billingDay, includeInNet, 0, null, now, now, null, deviceId))
                .copy(name = name, emoji = emoji, currency = currency, initialBalanceMinor = initialBalanceMinor, type = type, creditLimitMinor = creditLimitMinor, billingDay = billingDay, includeInNet = includeInNet, updatedAt = now, deviceId = deviceId)
            db.accountDao().upsert(e)
            db.outboxDao().enqueue(OutboxEntity("account", e.id, now))
        }
    }

    /** 删除保护（spec §9.2）：有交易→归档；无交易→物理墓碑删除。返回实际发生的操作。 */
    suspend fun archiveOrDelete(id: String): String {
        val now = System.currentTimeMillis()
        val hasTx = db.transactionDao().countByAccount(id) > 0
        db.withTransaction {
            if (hasTx) {
                db.accountDao().upsert(db.accountDao().getById(id)!!.copy(archivedAt = now, updatedAt = now, deviceId = deviceId))
                db.outboxDao().enqueue(OutboxEntity("account", id, now))
            } else {
                db.accountDao().softDelete(id, now)
                db.outboxDao().enqueue(OutboxEntity("account", id, now))
            }
        }
        return if (hasTx) "archived" else "deleted"
    }
}
```

```kotlin
package org.zero.wumi.ui.record

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.*

import org.zero.wumi.data.local.entity.CategoryType
import org.zero.wumi.data.local.entity.TxType
import org.zero.wumi.data.repo.AccountRepository
import org.zero.wumi.data.repo.CategoryRepository
import org.zero.wumi.data.repo.TransactionRepository
import org.zero.wumi.util.Money
import javax.inject.Inject

data class RecordUiState(
    val type: Int = TxType.EXPENSE,
    val amountText: String = "",
    val categories: List<CategoryEntity> = emptyList(),
    val accounts: List<AccountEntity> = emptyList(),
    val selectedCategoryId: String? = null,
    val selectedAccountId: String? = null,
    val selectedTargetAccountId: String? = null,
    val note: String = "",
    val date: Long = 0L,               // 0 = 现在
    val canSave: Boolean = false,
)

@HiltViewModel
class RecordViewModel @Inject constructor(
    private val txRepo: TransactionRepository,
    accountRepo: AccountRepository,
    categoryRepo: CategoryRepository,
) : ViewModel() {
    private val _type = MutableStateFlow(TxType.EXPENSE)
    private val _amount = MutableStateFlow("")
    private val _categoryId = MutableStateFlow<String?>(null)
    private val _accountId = MutableStateFlow<String?>(null)
    private val _targetAccountId = MutableStateFlow<String?>(null)
    private val _note = MutableStateFlow("")
    private val _date = MutableStateFlow(0L)
    /** 记住上次选择（spec §7.2） */
    private var lastExpenseCategoryId: String? = null
    private var lastIncomeCategoryId: String? = null

    private val categories = _type.flatMapLatest { t ->
        val ct = if (t == TxType.INCOME) CategoryType.INCOME else CategoryType.EXPENSE
        categoryRepo.observeActive(ct)
    }
    private val accounts = accountRepo.observeAll()

    val uiState: StateFlow<RecordUiState> = combine(
        _type, _amount, categories, accounts, _categoryId, _accountId, _targetAccountId, _note, _date,
    ) { arr ->
        @Suppress("UNCHECKED_CAST")

        val accs = arr[3] as List<AccountEntity>
        val type = arr[0] as Int
        val amount = arr[1] as String
        val catId = arr[4] as String?
        val accId = arr[5] as String?
        val targetId = arr[6] as String?
        RecordUiState(
            type = type, amountText = amount, categories = cats, accounts = accs,
            selectedCategoryId = catId, selectedAccountId = accId, selectedTargetAccountId = targetId,
            note = arr[7] as String, date = arr[8] as Long,
            canSave = Money.parseToMinor(amount, 2)?.let { it > 0 } == true
                    && accId != null
                    && (type == TxType.TRANSFER || cats.isEmpty() || catId != null)
                    && (type != TxType.TRANSFER || (targetId != null && targetId != accId)),
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), RecordUiState())

    fun setType(t: Int) {
        _type.value = t
        // 切换类型时恢复上次分类（spec：智能预选）
        _categoryId.value = if (t == TxType.INCOME) lastIncomeCategoryId else lastExpenseCategoryId
    }
    fun selectCategory(id: String?) {
        _categoryId.value = id
        if (_type.value == TxType.INCOME) lastIncomeCategoryId = id else lastExpenseCategoryId = id
    }
    fun selectAccount(id: String) { _accountId.value = id }
    fun selectTargetAccount(id: String) { _targetAccountId.value = id }
    fun setNote(s: String) { _note.value = s }
    fun setDate(millis: Long) { _date.value = millis }

    /** 金额状态机：≤9 位整数 + ≤2 位小数、单小数点、去前导零（spec §5.3 输入层限制）。 */
    fun inputDigit(c: Char) {
        val cur = _amount.value
        when {
            c == '.' -> if (!cur.contains('.')) _amount.value = if (cur.isEmpty()) "0." else "$cur."
            c.isDigit() -> {
                val hasDot = cur.contains('.')
                val intLen = if (hasDot) cur.substringBefore('.').length else cur.length
                val fracLen = if (hasDot) cur.substringAfter('.').length else 0
                when {
                    !hasDot && cur == "0" -> _amount.value = c.toString()               // 去前导零
                    !hasDot && intLen >= 9 -> Unit                                      // 9 位上限
                    hasDot && fracLen >= 2 -> Unit                                      // 2 位小数上限
                    else -> _amount.value = cur + c
                }
            }
        }
    }
    fun backspace() { _amount.value = _amount.value.dropLast(1) }
    fun clearAmount() { _amount.value = "" }

    fun save(onDone: () -> Unit) {
        val s = uiState.value
        val amount = Money.parseToMinor(s.amountText, 2) ?: return
        val accId = s.selectedAccountId ?: return
        viewModelScope.launch {
            val now = System.currentTimeMillis()
            val date = if (s.date == 0L) now else s.date
            when (s.type) {
                TxType.EXPENSE -> txRepo.addExpense(amount, "CNY", amount, accId, s.selectedCategoryId, date, s.note)
                TxType.INCOME -> txRepo.addIncome(amount, "CNY", amount, accId, s.selectedCategoryId, date, s.note)
                TxType.TRANSFER -> txRepo.addTransfer(amount, "CNY", amount, accId, s.selectedTargetAccountId!!, date, s.note)
            }
            // 重置但保留账户选择（3 秒记下一笔）
            _amount.value = ""; _note.value = ""; _date.value = 0L
            onDone()
        }
    }
}
```

```kotlin
package org.zero.wumi.ui.overview

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.launch
import org.zero.wumi.data.local.dao.MonthSums
import org.zero.wumi.data.local.dao.TxWithRefs
import org.zero.wumi.data.repo.TransactionRepository
import java.time.Instant
import java.time.LocalDate
import java.time.YearMonth
import java.time.ZoneId
import javax.inject.Inject

data class DayGroup(val date: LocalDate, val dayTotalMinor: Long, val items: List<TxWithRefs>)

@HiltViewModel
class OverviewViewModel @Inject constructor(
    private val txRepo: TransactionRepository,
) : ViewModel() {
    private val zone: ZoneId = ZoneId.systemDefault()
    private val _month = MutableStateFlow(YearMonth.now(zone))
    val month: StateFlow<YearMonth> = _month.asStateFlow()

    val days: StateFlow<List<DayGroup>> = _month.flatMapLatest { m ->
        val from = m.atDay(1).atStartOfDay(zone).toInstant().toEpochMilli()
        val to = m.plusMonths(1).atDay(1).atStartOfDay(zone).toInstant().toEpochMilli()
        txRepo.observeRange(from, to)
    }.map { list ->
        list.groupBy { Instant.ofEpochMilli(it.tx.date).atZone(zone).toLocalDate() }
            .map { (date, items) ->
                val total = items.sumOf { ref ->
                    when (ref.tx.type) {
                        0 -> -ref.tx.baseAmountMinor   // 支出
                        1 -> ref.tx.baseAmountMinor    // 收入
                        else -> 0L                     // 转账不计日小计
                    }
                }
                DayGroup(date, total, items)
            }
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), emptyList())

    val sums: StateFlow<MonthSums> = _month.flatMapLatest { m ->
        val from = m.atDay(1).atStartOfDay(zone).toInstant().toEpochMilli()
        val to = m.plusMonths(1).atDay(1).atStartOfDay(zone).toInstant().toEpochMilli()
        txRepo.observeMonthSums(from, to)
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), MonthSums(0, 0))

    fun prevMonth() { _month.value = _month.value.minusMonths(1) }
    fun nextMonth() { _month.value = _month.value.plusMonths(1) }
}
```

```kotlin
package org.zero.wumi.data.backup

import androidx.room.withTransaction
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import kotlinx.serialization.Serializable
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json
import org.zero.wumi.data.local.WumiDatabase
import org.zero.wumi.data.local.entity.*
import java.io.File
import java.time.LocalDateTime
import java.time.format.DateTimeFormatter

@Serializable data class BackupFile(
    val formatVersion: Int = 1,
    val exportedAt: String,
    val accounts: List<AccountEntity>,
    val categories: List<CategoryEntity>,
    val transactions: List<TransactionEntity>,
    val settings: List<SettingEntity>,
)

/** 本地备份（spec §9.2：先写临时文件再原子 rename；滚动 7 份）。 */
class BackupManager(private val db: WumiDatabase, private val dir: File) {
    private val json = Json { prettyPrint = true }
    private val stamp = DateTimeFormatter.ofPattern("yyyyMMdd-HHmmss")

    init { dir.mkdirs() }

    suspend fun backupNow(): File = withContext(Dispatchers.IO) {
        val snapshot = BackupFile(
            exportedAt = LocalDateTime.now().format(DateTimeFormatter.ISO_LOCAL_DATE_TIME),
            accounts = db.accountDao().allForBackup(),
            categories = db.categoryDao().allForBackup(),
            transactions = db.transactionDao().allForBackup(),
            settings = db.settingDao().allForBackup(),
        )
        val tmp = File(dir, "wumi-backup-${LocalDateTime.now().format(stamp)}.json.tmp")
        tmp.writeText(json.encodeToString(snapshot))
        val final = File(dir, tmp.name.removeSuffix(".tmp"))
        if (!tmp.renameTo(final)) { tmp.delete(); error("backup rename failed: ${tmp.path}") }
        final
    }

    suspend fun rotate(keep: Int = 7) = withContext(Dispatchers.IO) {
        dir.listFiles { f -> f.name.startsWith("wumi-backup-") && f.name.endsWith(".json") }
            ?.sortedByDescending { it.name }
            ?.drop(keep)
            ?.forEach { it.delete() }
        Unit
    }

    suspend fun restoreFrom(file: File) = withContext(Dispatchers.IO) {
        val data = json.decodeFromString<BackupFile>(file.readText())
        db.withTransaction {
            db.clearAllTables()
            data.accounts.forEach { db.accountDao().upsert(it) }
            data.categories.forEach { db.categoryDao().upsert(it) }
            data.transactions.forEach { db.transactionDao().insert(it) }
            data.settings.forEach { db.settingDao().put(it) }
        }
    }
}
```

```kotlin
package org.zero.wumi.data.export

import org.zero.wumi.data.local.dao.TxWithRefs
import org.zero.wumi.data.local.entity.TxType
import org.zero.wumi.util.Money
import java.time.Instant
import java.time.ZoneId
import java.time.format.DateTimeFormatter

/** RFC 4180 CSV 导出（spec §8 v0.1 交付项；对齐钱迹"导出永远免费"口碑基线）。 */
object CsvExporter {
    private val dateFmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")

    fun export(rows: List<TxWithRefs>): String = buildString {
        appendLine("日期,类型,分类,账户,金额,币种,备注")
        rows.forEach { r ->
            appendLine(listOf(
                Instant.ofEpochMilli(r.tx.date).atZone(ZoneId.systemDefault()).format(dateFmt),
                when (r.tx.type) { TxType.EXPENSE -> "支出"; TxType.INCOME -> "收入"; else -> "转账" },
                r.category?.name ?: "",
                r.account?.name ?: "",
                formatAmount(r),
                r.tx.currency,
                r.tx.note,
            ).joinToString(",") { escape(it) })
        }
    }

    private fun formatAmount(r: TxWithRefs): String {
        val sign = when (r.tx.type) { TxType.EXPENSE -> "-"; TxType.INCOME -> "+"; else -> "" }
        return sign + Money.format(r.tx.amountMinor, r.tx.currency).drop(1)   // 去货币符号，金额列纯数字
    }

    internal fun escape(field: String): String =
        if (field.any { it == ',' || it == '"' || it == '\n' || it == '\r' })
            "\"" + field.replace("\"", "\"\"") + "\""
        else field
}
```
